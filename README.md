# Personal Finance

Консольное Java-приложение для учёта личных финансов: регистрация и вход пользователей, категории доходов и расходов, операции, бюджеты по категориям, статистика и оповещения о превышении лимитов. Данные сохраняются в `data.json`.

## Запуск

Требования: Java 17+, Gradle Wrapper.

```bash
./gradlew build
```

Запустите главный класс `ru.personal.finance.Main` из IntelliJ IDEA.

Данные пользователей сохраняются в файл `data.json` в рабочей директории при выходе из приложения (`exit`) и загружаются при старте.

## Команды

| Команда | Описание |
|---------|----------|
| `create <login> <password>` | создать пользователя |
| `login <login> <password>` | войти в систему |
| `logout` | выйти из учётной записи |
| `category add <name> <income\|expense>` | создать категорию |
| `category` | показать список категорий |
| `budget add <category> <amount>` | установить бюджет категории |
| `budget <category>` | показать бюджет категории |
| `budget` | показать все установленные бюджеты |
| `income <category> <amount>` | добавить доход |
| `expense <category> <amount>` | добавить расход |
| `stats` | показать полную статистику |
| `stats <category> [category...]` | статистика по выбранным категориям |
| `help` | показать перечень команд |
| `exit` | завершить работу с программой |
